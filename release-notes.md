# Release v4.7.1

Please ensure your system is updated to version 4.7.1.
The "Red Zone Report" page has been renamed to "Agent Profile."
It now includes more comprehensive details about each agent, covering all their technical metrics—such as coaching, quality, and talk time—essentially providing a complete profile for the agent.
The page now lists all employees, allowing you to view the profile of any staff member, not just those in the "Red Zone."
Additionally, a filter has been added, which you can use if you wish to view only the "Red Zone" employees.
